SNEHSHISH AHUJA — PERSONAL PORTFOLIO

Files:
- index.html: the website page
- style.css: the design and styling used by index.html

IMPORTANT:
You do not need to open style.css in WPS Office.
WPS may show an unsupported-file message for this type of website file.
Keep style.css in the same folder as index.html. When you open index.html
in a web browser, the design is applied automatically.

To preview the website:
1. Extract all files from the ZIP.
2. Keep index.html and style.css together in the same folder.
3. Open index.html using Chrome, Edge, Firefox or another web browser.
4. Do not rename either file.

Design direction:
Dark navy backgrounds, blue-toned surfaces and light-blue highlights.
The website uses HTML and CSS only, with no JavaScript.

Before publishing:
1. Check that your personal details and academic marks are accurate.
2. The LinkedIn button points to:
   https://www.linkedin.com/in/snehshish-ahuja-030b42424/

GitHub Pages:
Upload index.html and style.css to the root of your GitHub repository.
Then go to Settings > Pages and publish from the main branch and root folder.
